# Station2EPW Desktop

**Station2EPW Desktop — EPW and PVsyst Weather Data Converter**

Developed by **Tarık Aykan** under **betanova.tech**.

## 1. Project Overview

Station2EPW Desktop is a Windows-first Python desktop application that converts hourly station weather data (`.csv` / `.xlsx`) into simulation-ready outputs for:

- EnergyPlus / CBE Clima Tool / Ladybug (`.epw`)
- PVsyst import workflows (`_pvsyst.csv`, `.SIT`, `.MEF` templates)
- Station2EPW internal project manifest (`.pvsyst` JSON manifest)

The application performs schema mapping, unit conversion, quality control, and structured export in a wizard-like UI.

## 2. Features

- CSV/XLSX reader with encoding fallback and delimiter sniffing
- Datetime split (`year/month/day/hour/minute`) or explicit time columns
- Automatic column-guess rules for Turkish/English naming variants
- Unit conversion (temperature, pressure, wind, radiation, albedo)
- Data quality checks (time continuity, duplicates, physical limits, missing ratios)
- EPW export with official hourly column order and missing value codes
- PVsyst-compatible export package (CSV + SIT + MEF + report + optional manifest)
- TXT reporting inside app and file export

## 4. EnergyPlus EPW Export

- Header lines: `LOCATION`, `DESIGN CONDITIONS`, `TYPICAL/EXTREME PERIODS`, `GROUND TEMPERATURES`, `HOLIDAYS/DAYLIGHT SAVINGS`, `COMMENTS 1`, `COMMENTS 2`, `DATA PERIODS`
- Official 35-column hourly record sequence preserved in `app/core/epw_schema.py`
- EPW `Hour` normalization: `0..23` -> `1..24`
- Missing/default field values follow EnergyPlus conventions

## 5. PVsyst-Compatible Export

Generated via `app/core/pvsyst_writer.py`:

- `{base}_pvsyst.csv`
- `{base}_pvsyst.SIT`
- `{base}_pvsyst.MEF`
- `{base}_processed.csv` (optional)
- `{base}_pvsyst_report.txt`

PVsyst CSV contains metadata comment lines and weather columns:

- Date, Time
- Global Horizontal Irradiance (GHI)
- Diffuse Horizontal Irradiance (DHI)
- Direct Normal Irradiance (DNI)
- Ambient Temperature
- Wind Speed
- Relative Humidity
- Precipitation
- Albedo

## 6. What is the `.pvsyst` file?

The `.pvsyst` file generated by Station2EPW Desktop is a project manifest file for tracking generated outputs. It is not a native PVsyst meteo file. For PVsyst import, use the generated CSV together with the SIT and MEF templates and verify import settings inside PVsyst.

## 11. Data Quality Checks

General checks include:

- File readability
- Total records, 8760/8784 expectations
- Missing/duplicate timestamps
- Chronological order
- Physical ranges: temperature, dew point, humidity, pressure, wind
- Radiation sanity: negative GHI/DHI/DNI, `DHI > GHI`
- Cloud cover range
- Negative precipitation
- Missing data ratio

PVsyst-specific checks include:

- Presence of GHI/DHI/DNI, ambient temperature, wind speed
- Night-time suspicious irradiance
- Albedo in `0..1`

## 12. Known Limitations

- Native PVsyst `.MET` file generation is not included in MVP
- `.MEF` template may need manual adjustment depending on PVsyst version
- `.pvsyst` is a Station2EPW manifest, not a native PVsyst meteo data file
- Full-year assumptions may produce warnings on partial datasets
